# Todo App (React + Redux Toolkit)

This is a small starter project using Vite, React, and Redux Toolkit.

Quickstart (PowerShell):

```powershell
# 1) install dependencies
npm install

# 2) start dev server
npm run dev
```

Files of interest:

- `src/main.jsx` — app entry
- `src/store.js` — Redux Toolkit store
- `src/features/todos/todosSlice.js` — todos slice
- `src/features/todos/Todos.jsx` — simple UI

Notes:

- This is plain JavaScript (no TypeScript) and minimal CSS.
- After running `npm install` run `npm run dev` and open the local dev URL shown in the terminal.
